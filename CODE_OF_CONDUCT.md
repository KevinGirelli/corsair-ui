# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Everyone taking part in issues, pull requests and discussions is expected to uphold it.

In short: be respectful and constructive, assume good intent, and keep criticism about the code, not the person. Harassment, discriminatory language and personal attacks are not tolerated.

## Reporting

If someone's behaviour worries you, contact the maintainer, [@KevinGirelli](https://github.com/KevinGirelli), through the contact details on his GitHub profile. Reports are handled privately.
