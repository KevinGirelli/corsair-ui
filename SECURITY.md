# Security policy

Corsair UI items are copied into your project as source code, so a vulnerability in an item (for example an XSS through unescaped HTML) ends up in every project that installed it. Reports are very welcome.

## Reporting a vulnerability

Please report it privately through [GitHub's private vulnerability reporting](https://github.com/KevinGirelli/corsair-ui/security/advisories/new) rather than in a public issue or pull request. Include the affected item, how it can be exploited and, if you can, a suggested fix.

## Supported versions

There are no releases yet. Fixes land on `main`; if you installed an affected item, re-run `shadcn add` for it or apply the patch from the advisory to your copy.
